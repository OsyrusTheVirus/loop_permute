# Implementation of Linear Algebra Operations

This is for Science of High Performance Computing (CS 333P) at UT Austin.
I'm using this to reference the plotting using octave

Here are the steps:

1. run "make driver"
2. run "driver.x 3 100 1500 200 > ./util/data_loopperm.m" 
    Must be called data_loopperm.m because that's how plot_all.m accessess data
3. run "cd ./util/"
4. run "ocatve plot_all.m"

There should be a pdf you can download.
